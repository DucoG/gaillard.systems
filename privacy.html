Privacy Policy

Last updated: 19 November 2026

This page covers the private Google API integration run by Gaillard Systems (the "app", shown on Google consent screens as "Claude Google MCP"). The app is a personal productivity tool. It is used only by its owner, Duco Gaillard, to work with the owner's own Google accounts. It is not offered to the public, and no other person's Google data is accessed.

What the app accesses

With the owner's explicit consent, through Google's OAuth flow, the app can access the owner's own:

  • Gmail: search and read messages, create drafts, and send messages when the owner asks.
  • Google Calendar: read, create and update events.
  • Google Drive: search, read, upload and share files.

How the data is used

Data is used only to carry out tasks the owner requests, such as finding an email, drafting a reply, checking availability, or retrieving a document. It is not used for advertising, profiling, or training of any machine-learning model, and it is not sold.

Storage and sharing

  • The app runs on the owner's own computer. OAuth tokens are stored locally, in a file readable only by the owner.
  • Google data is not transferred to or shared with third parties, except as needed to fulfil a request the owner makes in the moment (for example, when the owner asks an AI assistant to summarise an email, the relevant text is processed by that assistant to answer that request).
  • No Google user data is stored on this website. This website is a static page and collects no user data from the app.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

The owner can revoke the app's access at any time at myaccount.google.com/permissions and delete the locally stored tokens from the owner's computer.
